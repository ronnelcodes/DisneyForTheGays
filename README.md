# Disney for the Gays

A mobile-friendly May 2027 Disneyland group-trip landing page ready for GitHub and Netlify.

The response form is embedded from Jotform form `262347048050048`. Jotform owns submission storage, attendee autoresponder emails, organizer notifications, and Google Sheets synchronization. Netlify only hosts the landing page and background; it does not process form submissions.

## Deploy

1. Upload all repository files to GitHub.
2. Connect the repository to Netlify.
3. Deploy with the repository root as the publish directory and no build command.
4. Submit one response through the published website.
5. Verify the attendee email, organizer notification, and connected Google Sheets worksheet.
